# State Context

## Purpose

Hold short-lived operational memory so another agent can resume current work quickly.

Read `CURRENT.md` before continuing active work and `decisions.md` for recent cross-cutting choices. Update state after meaningful progress, blockers, or handoffs. Do not accumulate domain knowledge, research evidence, specifications, or enduring technical rationale here; move those to their owning contexts. Prune stale state instead of preserving a diary.
