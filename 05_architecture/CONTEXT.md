# Architecture Context

## Purpose

Hold technical design and durable engineering decisions needed to realize the product.

Route here for system boundaries, components, data, interfaces, and technical decisions. Read product requirements and constraints first, then only relevant architecture artifacts. Modify designs with rationale, alternatives, consequences, and links to requirements. Product scope belongs in `04_product/`; task execution belongs in `06_build/`; application code belongs in `app/`. Use `_research/` when a technical claim requires external verification rather than guessing.

## Expected output

An implementable technical design with traceable decisions and clearly marked unknowns.
